# MediaAssistant 安装与使用

## 安装插件

基于 Emby 4.9 / .NET 8，已在 Docker Emby 4.10.2.0 测试。Windows、Linux、macOS 使用同一份 `MediaAssistant.dll`。

从 [最新发布页](https://github.com/xiarenyyds/MediaAssistant/releases/latest) 下载 DLL，将其放到 Emby 插件目录。Docker 通常为容器内 `/config/plugins`，请对应实际宿主机挂载目录。重启 Emby 后打开网页。下载文件可用发布页的 `SHA256SUMS.txt` 校验。

主程序不附带插件；MDCx“媒体助手”右上角的“下载插件”也可下载最新稳定版。

## 连接 MDCx

1. 在 MDCx 主菜单打开“媒体助手”，设置监听地址、端口并生成令牌。
2. 路径相同且 MDCx 可访问时无需配置映射。路径不同时再添加：左边为 Emby 看到的目录，右边为 MDCx 可访问的真实目录。例如 `/media/movies` → `/Volumes/Media/Movies`，目录以下相对路径不变。多条规则优先匹配最长根目录；未匹配时直接使用传入路径。
3. 点击页面底部统一的“保存”，再点击“开始监听”。需要下次自动开启时勾选“随软件启动监听”。这些配置跟随当前主配置保存和切换。
4. 在 Emby 媒体助手设置中填写可访问的 MDCx 地址，如 `http://192.168.1.10:13114`，以及同一个令牌。Docker 内的 `127.0.0.1` 指向容器自身，连接地址不能填写 `0.0.0.0`。
5. MDCx 必须能读写对应媒体目录。插件不传输视频，路径映射只定位同一份共享媒体。

## 影片和演员菜单

Emby Web 管理员的单部影片菜单提供完整刮削、重读元数据、搜索封面、编辑封面、翻译标题和简介。

完整刮削固定使用后端正常模式，其他网站、翻译、NFO、图片和命名规则读取当前保存的配置；原位更新 NFO 和图片，不移动或重命名视频。“重读元数据”只让 Emby 重新读取影片旁的本地 NFO，不联网、不翻译、不写回 NFO；缺少 NFO 时提示错误。媒体库需启用本地 NFO 读取器，无需注册 MediaAssistant 影片或图片刮削器。

搜索封面只查询后端当前模式要求的图片来源，按配置可加入 Amazon 高清竖图。横图与独立竖图分组选择：横图用于背景和缩略图，封面使用独立竖图或横图裁剪结果。编辑封面读取已有图片，也可上传或拖入 JPEG、PNG、WebP，最大 20 MiB；预览不修改文件，确认后才保存。本次明确勾选的裁剪、水印和输出设置优先于后端默认值。

演员菜单提供资料和图片搜索，可分别替换简介、头像或背景图。

## 计划任务

在插件设置中分别勾选批量翻译、封面洗版和重读元数据的媒体库，三个列表互不影响，未选择时不执行。

| 任务 | 行为 |
| --- | --- |
| 封面洗版 | 只检查背景图，默认最低宽 800、高 535、大小 0 KB；合格时跳过，缺失或低质量时交后端复核及处理 |
| 重读元数据 | 遍历选中媒体库已入库的影片，逐部重读本地 NFO；不扫描新增媒体，不联网，不要求 MDCx 在线 |
| 翻译标题和简介 | 后端扫描选中目录的 NFO，跳过空内容和已是中文的文本，翻译保存后通知 Emby 重读 |
| 检查插件更新 | 检查本仓库的最新稳定版，校验 SHA-256、程序集名称和版本，替换后需重启 Emby |

洗版需要替换背景图时，联动更新确认由它派生的封面及缩略图，独立图片保留。新背景需满足质量规则；没有更好候选时保留已有图片。背景缺失时优先补合格横图，仅有竖图不能充当背景。需要重新生成封面时按后端 Amazon 开关搜索高清竖图，未找到则裁剪新横图。背景合格时不因其他图片缺失触发洗版。

## 外部播放器

在 Emby 媒体助手设置中启用外部播放器，并多选需要的播放器。详情页按当前设备显示图标，多个媒体版本可在同一行选择：

| 设备 | 可显示的播放器 |
| --- | --- |
| Windows | PotPlayer |
| macOS | IINA、Infuse、SenPlayer |
| iOS / iPadOS | Infuse、nPlayer、VLC、SenPlayer |
| Android | nPlayer、VLC、MX Player 普通版或专业版 |

需在浏览器所在设备安装对应播放器，并允许打开外部应用。不需要 MDCx 在线；播放读取 Emby 鉴权原始流，不映射本地文件、不自动转码，也不回传播放进度或自动加载外置字幕。IINA 可使用已有续播位置。播放链接包含当前登录用户的访问令牌，请勿分享。播放器图标及标识归各自权利人所有。

## 任务与日志

MDCx 后端任务进度、失败原因和重试位于“日志管理 → 媒体助手”。停止监听只暂停后续任务，已开始任务完成后停止领取。

Emby 侧日志位于其日志目录的 `plugin/` 下，按任务类型分别记录开始、逐片结果、结束统计和失败原因。Docker 中通常为 `/config/logs/plugin/`。
